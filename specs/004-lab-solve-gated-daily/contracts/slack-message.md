# Contract: Slack 메시지 변경분

002의 [contracts/slack-message.md](../../002-lab-troubleshoot-practice/contracts/slack-message.md)에서 바뀌는 부분만 적는다.
모든 메시지는 `{"text": <알림용 요약>, "blocks": [...]}` 형식이고, 봇 토큰 게시에도 그대로 쓴다.

## 오늘의 문제

- 기존 본문 그대로. catchup 형식은 더 이상 만들지 않는다.
- "밀린 문제" 줄을 뺀다.
- 맨 아래 context 블록에 한 줄을 더한다:
  `다 풀면 이 메시지에 ✅를 달아 주세요. /lab-check로 해결하면 자동으로 달려요. ✅가 있어야 다음 문제가 올라와요.`

## 리마인드 (열린 문제 메시지의 스레드 답글)

```text
⏳ 아직 해결 전이에요 · 게시 후 {N}일
✅가 달리면 다음 날 아침에 다음 문제가 올라와요.
```

N ≥ 3이고 힌트가 있으면 아래를 덧붙인다(힌트 본문은 `hints.md`의 `## 힌트 1` 내용 그대로, mrkdwn 이스케이프):

```text
💡 힌트 1단계
{힌트 1 본문}
더 필요하면 /lab-hint
```

`text`(알림 요약): `아직 해결 전: {문제 제목}`.

## 재게시 (메시지가 없어졌을 때)

오늘의 문제 본문 맨 위에 context 한 줄: `이전 메시지를 찾을 수 없어 같은 문제를 다시 올려요.`

## 주간 요약

- "해결한 시나리오 / 포기 / 힌트" 줄은 그대로.
- 새 줄: `오늘의 문제: 해결 {solved_posts} · 미해결로 멈춘 날 {stalled_days}일`
- "밀린 문제 {backlog}개" 줄을 `지금 열린 문제: {제목} (게시 후 {N}일)`로 바꾼다. 열린 문제가 없으면 줄을 뺀다.

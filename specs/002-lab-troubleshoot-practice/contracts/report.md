# Contract: 장애 보고서

경로는 `agents/troubleshoot-lab/docs/reports/<YYYY-MM-DD>-<scenario id>-<attempt>.md`이다(날짜는 시도 종료일, KST).
템플릿은 `templates/report.md`이고, 커리큘럼 §6 형식에 면접 질문 답변 섹션을 더했다.

## 생성되는 초안

```markdown
# {장애명 = 시나리오 제목}

> 시나리오 #{curriculum_no} · 분야 {대표 분야} · 시도 {attempt} · 결과 {해결|포기} · 힌트 {n}개 사용
> 이 파일은 레포에 커밋되면 공개돼요. 개인정보나 비밀값을 쓰지 마세요.
```

**측정표 칸 표기**

| 경우 | 표기 |
|------|------|
| 실측값 | 숫자(소수 1자리) |
| `unavailable` | "측정 불가" |
| `skipped` | "측정 생략(사유)" |
| `not_applicable` | "해당 없음" |
| 그 단계 측정이 없음 | "측정하지 않음" |

추정·보간·이전 시도 값은 쓰지 않는다(FR-017, SC-004).

## `--done` 검사

- **필수 섹션**: `## 증상`, `## 원인`, `## 분석 과정`, `## 해결 방법`, `## 재발 방지`, 그리고 `## 면접 질문 답변` 아래의 각 `### Q`
- **판정**: 각 섹션에서 HTML 주석과 공백을 뺀 텍스트가 1자 이상이어야 한다.
- **실패**: outcome `incomplete`, 빈 섹션 이름 목록, 종료 코드 1
- **성공**: `report_completed(attempt, report=<repo 상대 경로>, answered=<채워진 Q 수>)`, outcome `reviewed`
- **헤딩**: 사용자가 헤딩 이름을 바꾸면 그 섹션은 없는 것으로 보고 실패시킨다(빈 섹션과 같은 안내).
